# Ghost in the Machine submission checklist

Deadline: **1 November 2026, 12:29 p.m. IST**. Aim to publish 31 October evening IST. DEV article publication is the entry; a repository alone is not an entry.

- [x] New software project and repository during the challenge window.
- [x] Three implemented signal exhibits and original interface.
- [x] Open-weight AI integration, bounded proposals, and measured outcomes.
- [x] Free local runtime, no paid API or secrets.
- [x] Tests and reproducible deterministic evaluation.
- [ ] Review actual model evaluation and document model-specific limitations.
- [ ] Confirm hosted site and browser AI path on a compatible real browser.
- [ ] Record an authentic demo and add its URL to the DEV draft.
- [ ] Collect optional real visitor feedback; quote only with consent.
- [ ] Author reviews the article, particularly first-person statements.
- [ ] Add DEV profile; publish one English entry with `devchallenge` and `hf26challenge`.
- [ ] Explicitly list only implemented, evidenced partner categories.
- [ ] Verify public demo/repository/video links from a signed-out browser.
- [ ] Preserve a release commit and mark any later changes in README.

Primary category: **Best Use of Gemma**, provided the final demo/evidence actually demonstrates Gemma. Additional candidate: **Best Use of GitHub Copilot**, because the challenge lists GitHub Actions automation as a qualifying use; describe the implemented CI honestly and do not claim Copilot was used. No Render, Tinker, Sentry, or other service category is claimed without an actual integration. One participant may receive only one prize.

Rules: https://dev.to/challenges/hacktoberfest-week4-2026-10-26 and https://dev.to/page/hacktoberfest-week4-2026-10-26-contest-rules
